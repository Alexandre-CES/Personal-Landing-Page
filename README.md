# Personal Landing Page

Portfólio pessoal de Alexandre, feito com HTML e CSS. O site apresenta seus serviços, projetos, trabalhos para clientes e canais de contato.

## Visualização local

Abra `index.html` no navegador. As páginas internas ficam em `pages/` e os estilos e imagens estão em `style/` e `images/`.

## Estrutura

- `index.html`: apresentação e serviços
- `pages/projetos.html`: projetos de estudo
- `pages/trabalhos.html`: trabalhos para clientes
- `pages/contato.html`: canais de contato
